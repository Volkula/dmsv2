# Плагины ширмы

Список плагинов у комнаты пустой, пока мастер сам не добавит пункт. Имя берётся из `plugin.json` релиза, а не зашито в меню. Если GitHub не ответил, ширма читает тот же манифест из поставки.

Включение просит пароль комнаты. Ключ Яндекса после этого в интерфейс и в ответы API не возвращается: сервер хранит его шифром в таблице комнаты и использует только когда шлёт цвет на лампы.

## Ключ Яндекса

1. На [oauth.yandex.ru](https://oauth.yandex.ru) создайте приложение типа «Для доступа к API или отладки».
2. Права: `iot:view` и `iot:control`.
3. Подставьте свой Client ID в адрес и откройте его в браузере:

`https://oauth.yandex.ru/authorize?response_type=token&client_id=CLIENT_ID`

4. Токен показывается один раз, на странице `verification_code`. В ширме: меню → Плагины → добавить адаптивную подсветку → включить и вставить токен. Поле очищается сразу после отправки.

На почту, имя аккаунта и сам токен в репозиторий ничего не кладём. Скриншоты кабинета с адресом почты тоже не коммитим.

Цвет уходит только на лампы с моделью HSV. Колонки и розетки ширма не выбирает. Сцена устройства используется для эффекта таймера, только если такая сцена у лампы уже есть. Если Яндекс сцену не принял, ширма повторяет тот же цвет обычным HSV.
