# Ширма (dmsv2)

GM-экран для Volkula: карта, справочник, бой, броски. Две ссылки без аккаунтов — мастер и игроки.

## Быстрый старт

```bash
docker-compose up -d --build
```

Откройте [http://127.0.0.1:8088/](http://127.0.0.1:8088/).

| Сервис | Роль |
|--------|------|
| `caddy` | Один origin на `:8088` → статика `web/` и прокси `/api/*` |
| `api` | Node + SQLite, порт внутри сети `8080` |

Данные: volume `shirmo-data` → `/data` (SQLite и файлы).

> На серверах со старым `docker-compose` 1.29 используйте именно `docker-compose`, не `docker compose`. Если recreate падает с `ContainerConfig`, сделайте `docker-compose down`, удалите контейнеры `dms2_*` и снова `up -d --build`.

## Ссылки

- Главная `/` — создать комнату, список, корзина
- Мастер `/m/{id}` — правка кампании (нужен ключ)
- Игроки `/v/{id}` — только кадр и события

Ключ мастера выдаётся при создании. Он пишется в базу (`master_key`) и в браузер (`localStorage`). Без ключа правка недоступна; экран игроков открывается и без него.

Удаление комнаты уносит её в **корзину**; оттуда можно **вернуть**.

## Модули мастера

- **Сцена** — текстовая страница
- **Карта** — виды, локации, маркеры, диалог, товары
- **Справочник** — НПС, отряды, товары (материалы tentaculus.ru, CC BY-NC-SA 3.0)
- **Бой** — отряды, инициатива, статусы, атаки, лог; игрокам отдельный экран боя
- **Броски** — кубы с показом игрокам

Публикация: «Сразу» обновляет кадр при каждом сохранении активной страницы; «Только по кнопке» — после «Показать». Броски и пинги идут сразу.
